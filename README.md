# TaskForge — Enterprise Project & Task Management Platform

Jira-lite project management platform with task dependencies, priorities, role-based access, collaboration, notifications, search, and reporting dashboards.

## Features

- Organization and project management
- Task creation and management
- Task priorities and assignees
- Task dependencies
- User roles: Admin, Manager, Developer
- Comments
- File attachments
- Notifications
- Search and filtering
- Reporting dashboard with burndown-style statistics

## Tech Stack

**Backend**
- Java
- Spring Boot
- Spring Data JPA / Hibernate
- Spring Security
- PostgreSQL

**Frontend**
- Angular
- TypeScript
- SCSS

## Prerequisites

- Java (version)
- Maven
- Node.js
- npm
- Angular CLI
- PostgreSQL

## Project Structure


TaskForge is being built incrementally, milestone by milestone, as a learning-in-public Java Full Stack project.

| # | Milestone | Focus | Status |
|---|-----------|-------|--------|
| 0 | Environment & Repo Setup | Git, GitHub Flow, Maven/Angular scaffolding | ✅ Done |
| 1 | Domain Model | Core Java OOP, encapsulation, records, enums | 🔲 Planned |
| 2 | In-Memory Engine & DS&A | Collections, Streams, sorting, priority queues | 🔲 Planned |
| 3 | REST API Skeleton | Spring Boot, controllers, services, DTOs, validation | 🔲 Planned |
| 4 | Persistence Layer | Spring Data JPA, PostgreSQL, entity relationships | 🔲 Planned |
| 5 | Robust Error Handling | Exception hierarchy, global exception handling | 🔲 Planned |
| 6 | Security | Spring Security, JWT authentication, RBAC | 🔲 Planned |
| 7 | Advanced Queries | Pagination, sorting, filtering, JPA Specifications | 🔲 Planned |
| 8 | File Attachments | File upload/storage, Java I/O | 🔲 Planned |
| 9 | Notifications & Scheduling | Async processing, `@Scheduled`, email | 🔲 Planned |
| 10 | Performance | Caching, query optimization, indexing | 🔲 Planned |
| 11 | Testing (Backend) | JUnit, Mockito, integration testing | 🔲 Planned |
| 12 | Angular Foundations | TypeScript, components, routing, services | 🔲 Planned |
| 13 | Angular Data Layer | Reactive Forms, HttpClient, RxJS/Observables | 🔲 Planned |
| 14 | Angular Security | Auth, route guards, interceptors, role-based UI | 🔲 Planned |
| 15 | Angular at Scale | State management, lazy loading, performance | 🔲 Planned |
